# Wedding Decor - Next.js App

Website trang trí tiệc cưới được xây dựng với Next.js 15, React, Tailwind CSS và Framer Motion.

## Tính năng

- 🎨 Giao diện hiện đại, responsive
- 🌐 Đa ngôn ngữ (Tiếng Việt / English)
- 📸 Portfolio gallery với lightbox
- 🎭 Animation mượt mà với Framer Motion
- 📱 Mobile-friendly

## Công nghệ sử dụng

- Next.js 15
- React 19
- Tailwind CSS
- Framer Motion
- i18next (đa ngôn ngữ)
- Lucide Icons

## Cài đặt

```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git

# Di chuyển vào thư mục
cd YOUR_REPO

# Cài đặt dependencies
npm install

# Chạy development server
npm run dev
```

Mở [http://localhost:3000](http://localhost:3000) để xem kết quả.

## Build Production

```bash
npm run build
npm start
```

## Deploy

### Deploy lên Vercel (Khuyến nghị)

1. Push code lên GitHub
2. Import project vào Vercel
3. Vercel sẽ tự động detect Next.js và deploy

### Deploy lên Netlify

1. Build command: `npm run build`
2. Publish directory: `.next`

## Cấu trúc thư mục

```
nextjs-app/
├── app/
│   ├── components/     # React components
│   ├── pages/          # Page components
│   ├── data/           # Portfolio data
│   ├── constants/      # Constants (images, etc)
│   ├── i18n/           # Internationalization
│   ├── portfolio/      # Portfolio routes
│   └── services/       # Service routes
├── public/             # Static files
└── package.json
```
